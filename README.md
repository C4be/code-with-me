# Code with me

**Совместные занятия по программированию — на вашем компьютере.**

Code with me — настольное приложение для уроков, собеседований и парного решения задач. Ведущий открывает комнату, делится приглашением, а участники вместе работают над заданиями и кодом. После занятия можно сохранить шаблон с пустыми решениями или снимок комнаты и продолжить работу локально.

Приложение создано на **Tauri 2**, работает на **macOS, Windows и Linux** и поддерживает Python, Go, C++20 и Java.

## Что можно делать

- Создавать комнату на компьютере ведущего и приглашать до **10 участников** по публичной HTTPS-ссылке из любой сети.
- Подключаться к комнате в приложении, вставив ссылку в главном меню, или открыть её в браузере без установки приложения.
- Составлять контесты из задач с описанием в Markdown, формой задания и предварительным просмотром.
- Добавлять задачи кнопкой `++`; нумерация начинается с `0`.
- Писать несколько независимых решений к каждой задаче в отдельных вкладках.
- Совместно редактировать код и видеть курсоры и участников, работающих во вкладках.
- Выбирать язык решения, пользоваться подсветкой синтаксиса и запускать код.
- Переключаться между светлой и тёмной темами; по умолчанию тема следует настройке операционной системы.
- Сохранять занятие в `.cwmroom` как заготовку с пустыми решениями или как полный снимок.
- Импортировать сохранённое занятие как локальную комнату без сетевых подключений и редактировать его самостоятельно.

## Внешний вид

Рабочее пространство сосредоточено на двух областях: **условии задачи** и **редакторе кода**. Список задач помогает быстро переключаться между упражнениями, а кодовые вкладки относятся только к выбранной задаче.

## Быстрый старт для разработки

### Требования

- Node.js LTS
- pnpm 11.19.0
- Rust stable и компоненты сборки Tauri 2 для вашей ОС

Дополнительные системные зависимости Tauri перечислены в [официальном руководстве по подготовке окружения](https://v2.tauri.app/start/prerequisites/).

### Запуск

```bash
pnpm install
pnpm tauri dev
```

Чтобы запустить только веб-интерфейс в браузере:

```bash
pnpm dev
```

### Сборка установщика

Запускайте сборку на целевой ОС:

| Система | Команда | Результат |
| --- | --- | --- |
| macOS | `pnpm build:macos` | DMG |
| Windows | `pnpm build:windows` | NSIS `.exe` |
| Linux | `pnpm build:linux` | AppImage и DEB |

На macOS и Linux также доступен скрипт `bash scripts/build-desktop.sh`. В Windows используйте `build-windows.cmd` или `scripts/build-desktop.ps1`.

Сборки для всех трёх систем выполняются автоматически через GitHub Actions при push в `main`, pull request и вручную. Готовые установщики сохраняются как артефакты запуска workflow **Desktop builds**.

## Формат комнаты

Файл `.cwmroom` — переносимый пакет с описанием комнаты и её файлами. Вариант **template** сохраняет задачи и очищает решения; вариант **snapshot** сохраняет текущее содержимое целиком. При импорте занятие копируется в локальные данные приложения, исходный пакет остаётся нетронутым.

Задачи хранятся во внутреннем формате `.cwm.md`: YAML-поля задания и Markdown-текст. Кодовые файлы привязаны к задаче и решению, например `0.solution-0.py` или `1.solution-0.go`. В приложении файловое дерево не требуется: задачи и решения доступны через рабочие вкладки.

## Комнаты через интернет

При создании комнаты приложение запускает локальный сервер только на компьютере ведущего и открывает к нему временный защищённый HTTPS-туннель. Входящие порты роутера настраивать не нужно. Для туннеля приложение при первом запуске скачивает подходящий `cloudflared` из официального выпуска Cloudflare и проверяет SHA-256. Остановка комнаты закрывает и туннель, поэтому ссылка перестаёт работать.

Используются бесплатные Cloudflare Quick Tunnels. Cloudflare предназначает их для разработки и тестирования, не гарантирует доступность, а также ограничивает 200 одновременными проксируемыми запросами. Для работы сервиса у ведущего должен быть интернет; если провайдер или сеть блокирует Cloudflare, публичную комнату создать не получится. Туннель поддерживает WebSocket-синхронизацию. [Ограничения Quick Tunnels](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/trycloudflare/), [поддержка WebSocket](https://developers.cloudflare.com/cloudflare-one/faq/cloudflare-tunnels-faq/).

Ссылка служит приглашением и содержит секретный код комнаты: каждый, у кого есть ссылка, может просматривать и менять файлы занятия. Передавайте её только участникам. Содержимое комнаты проходит через инфраструктуру Cloudflare и через локальный сервер ведущего.

## Запуск кода и безопасность

Код синхронизируется между участниками, но каждая команда запускается **локально у того участника, который её запустил**; вывод отображается в его собственном терминале. Для запуска Python, Go, C++ и Java должны быть установлены соответствующие инструменты.

Запуск программ не является системной песочницей: код выполняется с правами текущего пользователя. Запускайте только код, которому доверяете.

## Текущие ограничения

- Публичные ссылки временные и рассчитаны на небольшие занятия. Для постоянного сервиса с собственным доменом и гарантией доступности потребуется настроенный управляемый туннель или отдельный сервер-ретранслятор.
- Одновременное редактирование передаётся с короткой задержкой; полноценное разрешение конфликтов через CRDT/OT пока не реализовано.
- Подсказки редактора базовые; языковые серверы (LSP), диагностика и автоформатирование пока не подключены.

## Структура проекта

- `app.js`, `*.css`, `index.html` — интерфейс приложения.
- `src-tauri/` — настольная оболочка, локальные команды и настройки сборки.
- `.github/workflows/build-desktop.yml` — матричная сборка macOS, Windows и Linux.
- `scripts/` — скрипты сборки для настольных систем.
- `landing.html` — промо-страница проекта.
