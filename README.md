# Code with me

**Совместное решение задач по программированию на занятиях и собеседованиях.** Ведущий запускает комнату на своём компьютере и отправляет ссылку. Гости открывают её в приложении или браузере, видят условие и вместе пишут код. После занятия каждый может сохранить задачи без решений или снимок комнаты и продолжить работу локально.

[Скачать для Windows, macOS и Linux](https://github.com/C4be/code-with-me/releases/latest) · [Сообщить о проблеме](https://github.com/C4be/code-with-me/issues)

## Установка

Откройте **Releases**, выберите файл для своей системы и установите его:

| Система | Файл в релизе | Как установить |
| --- | --- | --- |
| Windows x64 | `.exe` | Запустите установщик NSIS. |
| macOS, Apple Silicon (M1 и новее) | `aarch64.dmg` | Откройте образ и перенесите приложение в «Программы». |
| macOS, Intel | `x64.dmg` | Откройте образ и перенесите приложение в «Программы». |
| Ubuntu/Debian x64 | `.deb` | Установите пакет системным менеджером. |
| Другие Linux x64 | `.AppImage` | Разрешите выполнение файла и запустите его. Понадобятся системные библиотеки WebKitGTK. |

Файл `SHA256SUMS.txt` в релизе содержит контрольные суммы установщиков. Приложение можно открыть без Python, Go, C++ и Java; соответствующий инструмент нужен для **запуска** кода на выбранном языке. Раздел **«Проверка зависимостей»** в главном меню покажет, что установлено на вашем компьютере.

**Подпись сборок.** Публичные пакеты пока не подписаны сертификатами Apple Developer ID и Windows Code Signing. macOS может заблокировать первый запуск, а Windows показать SmartScreen. Для macOS воспользуйтесь [официальной инструкцией Apple «Open Anyway»](https://support.apple.com/en-gb/102445), только если скачали файл из релиза этого репозитория. Подпись и нотариализация macOS необходимы, чтобы убрать это предупреждение при обычной установке. Если после разрешения приложение не запускается, создайте issue с точным текстом предупреждения, версией macOS и типом процессора.

## Как провести занятие

1. Ведущий создаёт контест или открывает сохранённый, затем нажимает **«Создать комнату»**.
2. Ведущий копирует ссылку приглашения. Гость вставляет её в главном меню приложения или открывает в браузере.
3. Участники выбирают задачу, создают вкладки решений и пишут код. Вкладки принадлежат конкретной задаче; их нумерация начинается с `0`.
4. Каждый запускает код **на своём компьютере** и видит собственный терминал. Запуск на компьютере ведущего гостю не передаётся.
5. В конце занятия выберите **«Сохранить занятие»**: пустые решения для самостоятельной практики или полный снимок. Файл `.cwmroom` можно импортировать позднее как локальный контест без сетевой комнаты.

В одной комнате может быть **до 10 человек, включая ведущего**. Если ведущий закрывает комнату или соединение обрывается, гости видят, что изменения больше не синхронизируются, и могут сохранить свою копию. В браузере это скачиваемый `.cwmroom`; после дальнейших локальных правок его нужно скачать повторно.

## Возможности

- Две основные области рабочего пространства: условие задачи и код; редактор кода можно развернуть.
- Форма задания с названием, темой, подтемой, сложностью, временем, текстом и максимум пятью парами «ввод / вывод». Markdown писать вручную необязательно; есть отдельные режимы исходного текста и предпросмотра.
- Добавление задачи кнопкой `++`, удаление задач и вкладок, несколько независимых решений для одной задачи.
- Совместное редактирование кода, цветные курсоры и значки участников во вкладках. Имя у курсора скрывается через три секунды без действий.
- Python, Go, C++20 и Java: подсветка синтаксиса, базовые подсказки и запуск при наличии соответствующего инструмента. Необязательное локальное дополнение кода работает через Ollama и модель `qwen2.5-coder:1.5b`.
- Светлая и тёмная темы с выбором вручную или по настройке системы.
- Локальные и импортированные контесты, экспорт шаблона или полного снимка, настройки установленного программного обеспечения.

### Что хранится в файле занятия

`.cwmroom` — JSON-пакет с заданиями и решениями. **Шаблон** сохраняет условия и очищает кодовые окна; **снимок** сохраняет текущее содержимое. При импорте приложение создаёт локальную копию. Внутри пакета задания представлены файлами `.cwm.md` с полями YAML и текстом Markdown, а решения именуются, например, `0.solution-0.py` и `1.solution-0.go`. Пользователь работает через задачи и вкладки, без файлового дерева.

## Как работает подключение

Локальный сервер комнаты находится **на компьютере ведущего**. Общий сервер `code-with-me-app.ru` регистрирует комнату и передаёт участникам данные для установления WebRTC-соединения. Если прямой маршрут доступен, изменения и курсоры идут между компьютерами. Если сеть блокирует прямой маршрут, используется TURN-сервер как резервный путь. В интерфейсе показан выбранный маршрут и примерная задержка; сервер не хранит файлы комнаты. Данные WebRTC DataChannel защищены DTLS между участниками.

Ссылка приглашения содержит секрет комнаты. Любой, кто получил ссылку, может войти и менять содержимое; отдельной проверки гостя ведущим пока нет. Кнопка приглашения показывается только ведущему, однако уже полученную ссылку можно переслать вручную. Делитесь ей только с участниками занятия.

Соединение через TURN может быть медленнее прямого. Редактор быстро передаёт изменения, но при одновременной правке одного участка несколькими людьми пока используется синхронизация полного текста без CRDT/OT, поэтому возможны конфликты. Для сетей, разрешающих только HTTPS/443, резервный TURN на 3478 может быть недоступен.

## Локальный софт и безопасность

В главном меню **«Проверка зависимостей»** показывает Python, Go, C++, Java, Ollama и модель `qwen2.5-coder:1.5b`. Кнопки установки используют Homebrew на macOS, WinGet на Windows и пакетный менеджер Linux; система может запросить права администратора. Модель Ollama загружается отдельно и занимает примерно 1 ГБ. Раздел **«Настройки · Софт»** показывает расположение инструментов и позволяет удалить то, что приложение установило само. Дополнение кода обращается к локальному Ollama.

Запускаемый код исполняется с правами текущего пользователя, без отдельной системной песочницы. Запускайте только код, которому доверяете.

## Разработка

Проект использует **Tauri 2, Rust, JavaScript и Vite**. Для сборки нужны Node.js LTS, pnpm 11.19.0, Rust stable и [системные зависимости Tauri](https://v2.tauri.app/start/prerequisites/).

```bash
pnpm install
pnpm tauri dev
```

`pnpm dev` запускает только веб-интерфейс. Для локальных пакетов запускайте сборку на целевой ОС: `pnpm build:windows` (NSIS), `pnpm build:macos` (DMG) или `pnpm build:linux` (AppImage и DEB). Также доступны `scripts/build-desktop.sh`, `scripts/build-desktop.ps1` и `build-windows.cmd`.

Исходники интерфейса находятся в `app.js`, `index.html` и `studio.css`; настольные команды — в `src-tauri/`; WebRTC-канал — в `peer-transport.js`; сервер знакомства — в `rendezvous/`. GitHub Actions в `.github/workflows/build-desktop.yml` собирает четыре варианта приложения. При публикации тега `vX.Y.Z`, совпадающего с версией в `package.json`, workflow прикрепляет установщики и контрольные суммы к GitHub Release. Обычные push и pull request сохраняют сборки только как артефакты Actions.

### Свой сервер знакомства

`scripts/deploy-rendezvous.sh` собирает Go-сервер и веб-интерфейс, настраивает службу, Caddy для HTTPS и coturn для резервного соединения. Скрипт рассчитан на Ubuntu с `sudo`, Caddy и coturn; локально нужны Go, Node.js и pnpm. По умолчанию используются `code-with-me-app.ru` и SSH-ключ `~/.ssh/cloudru`:

```bash
bash scripts/deploy-rendezvous.sh
```

Для другого сервера: `bash scripts/deploy-rendezvous.sh example.com user@IP IP`. DNS-запись домена должна указывать на VPS. Разрешите входящие TCP 80/443, TCP и UDP 3478, UDP 49160–49200 и SSH 22. Настольное приложение с другим адресом сервера собирается с `CODE_WITH_ME_RENDEZVOUS_BASE=https://example.com`.

## Статус проекта

Это ранняя версия для небольших занятий. В планах — разрешение конфликтов при одновременном редактировании, улучшенные языковые подсказки, подписанные установщики и резервное подключение для сетей, где открыт только порт 443. Лицензия исходного кода пока не выбрана.
